Dabao signer

Talk to the touch-to-confirm Ethereum signer on a Baochip-1x Dabao board, straight from the browser. Nothing is installed: the page uses WebHID.

Test network only. Not audited. This is a demonstration for developers. The key in the board cannot be backed up, the board has no PIN, and it cannot show what it signs. Do not use it for anything of value.

1. Connect the board

This browser has no WebHID. Use Chrome or Edge on a computer.

Plug the board in and start the signer (press PROG if it is waiting in its bootloader). Then pick "Dabao HID" in the dialog.

2. Check the bootloader

The first code the chip runs is its bootloader. This reads the fingerprints (SHA-512) the bootloader reports for its two stages and compares them with builds that were rebuilt from the public source. The check runs in the bootloader, not in the signer, so the board has to be restarted into it.

This browser has no Web Serial. Use Chrome or Edge on a computer.

No signer connected? Put the board in its bootloader by hand: hold PROG, tap RESET, release PROG. Then click "Read and check" and pick the board's serial port.
